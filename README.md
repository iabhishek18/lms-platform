# Learning Management System (LMS)

Udemy-style platform with video courses, quizzes, certificates, progress tracking, and Stripe payments.

## Features
- 🎥 Video hosting via Mux
- 📚 Course creation with chapters
- ❓ Quiz & assessments per chapter
- 📊 Progress tracking
- 🎓 Auto-generated certificates
- 💳 Stripe payments for premium courses
- 👨‍🏫 Instructor dashboard
- 📱 Responsive design

## Tech Stack
- Next.js 14, Prisma, PostgreSQL, Mux, Stripe, Uploadthing, Tailwind

## Getting Started
```bash
npm install && cp .env.example .env && npx prisma db push && npm run dev
```
